# 🌟 StarRailAssistant (SRA)

🎮 Помощник для автоматизации Honkai: Star Rail.
Если при использовании SRA возникли проблемы, сначала прочитайте [руководство по их решению](https://starrailassistant.top/getting-started/trouble-shooting/).

Если проект вам полезен, поддержите его звёздочкой ⭐!

## ❓ Что такое SRA?

🤖 Программа на основе распознавания изображений, которая помогает выполнять повседневные задачи в Honkai: Star Rail — от запуска игры до выхода из неё.

![Главное окно StarRailAssistant](https://starrailassistant.top/_astro/softwaremain2.C3xP9Cen_6MuUy.webp)

## ⚠️ Отказ от ответственности

Это внешний инструмент для автоматизации игрового процесса в Honkai: Star Rail.
Он предназначен для взаимодействия с игрой только через существующий пользовательский интерфейс с соблюдением применимых законов и правил.
Программа не предназначена для нарушения игрового баланса или получения нечестного преимущества.
Она не изменяет игровые файлы или код.

Программа имеет открытый исходный код, распространяется бесплатно и предназначена только для обучения и обмена опытом.
Право окончательного толкования условий проекта остаётся за командой разработчиков.
Проект и команда разработчиков не несут ответственности за проблемы, возникающие при использовании программы.
Если кто-то использует SRA для платного прохождения игры за вас, плата может взиматься за оборудование, затраченное время и другие расходы. Проблемы и последствия таких услуг не относятся к ответственности проекта.

## ✨ Возможности

* 🎯 **Запуск игры**
  * Укажите путь к игре, логин и пароль — SRA выполнит запуск и вход. Поддерживается сервер Bilibili.
* ⚡ **Расходование энергии Освоения**
  * Выбирайте уровни, количество и порядок прохождений. Поддерживается автоматический подбор уровней и числа попыток по целям развития персонажей.
* 🎁 **Получение наград**
  * Ежедневная тренировка, Честь Безымянных, награды за использование персонажей поддержки, промокоды, поручения, награды за вход, почта и многое другое.
* 🚀 **Набор очков Расходящейся вселенной**
  * Автоматическая остановка при достижении недельного лимита очков и получение соответствующих наград.
* 🎲 **Валютные войны**
  * Автоматизация стандартных партий и режима разгона; победа на максимальной сложности не гарантируется.
  * Подбор старта по инвестиционной среде, инвестиционной стратегии, имени и модификаторам босса, например Совастьяна (叽米) или Авантюрина (砂金).
  * Также доступно расширение [CurrencyWarsPlus](extensions/cw_plus/README.md) от **YukkiSSYB**; описание и настройки приведены в его документации.
* 🚪 **Выход из игры**
  * При желании — закрытие SRA и выключение компьютера.
* 📖 **Автоматическое прохождение диалогов**
  * Просмотр сюжета без ручного пролистывания; поддерживается пропуск.
* 🔄 **Переключение между аккаунтами**
* **Облачная Honkai: Star Rail (云星穹铁道)**
  * Поддержка китайской облачной версии игры для работы в фоне.

## ⚠️ Важные замечания

* 🌐 **Язык игры**: для распознавания используйте **упрощённый китайский — 简体中文**. Русский интерфейс SRA не означает поддержку русского языка игры.
* 📺 **Требования к разрешению**:
  * Если разрешение экрана **выше 1080p**, запускайте игру в **оконном режиме 1920×1080**, иначе возможны ошибки распознавания!
  * Если разрешение экрана **равно 1080p**, запускайте игру в **полноэкранном режиме 1920×1080**, иначе возможны ошибки распознавания!
* 🖱️ **Важно**: **во время выполнения задач не выполняйте другие действия мышью и клавиатурой!**

## 🚀 Как начать пользоваться SRA?

⬇️ Скачать: [SRA](https://github.com/Shasnow/StarRailAssistant/releases/latest)

Описание выпусков и вариантов загрузки: [ChangeLog2.0.md](ChangeLog2.0.md).

Требования к среде выполнения:

Для версий, содержащих `StarRailAssistant_DesktopDLC`, требуется [.NET Desktop Runtime 10.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0).

Для версий, содержащих `StarRailAssistant_ServerDLC`, требуется [ASP.NET Core Runtime 10.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0).

* Скачайте файл `StarRailAssistant_vX.X.X.zip` со страницы Releases — *всё уже подготовлено*. Распакуйте архив в удобную папку и запустите `SRA.exe`!
* Для WebUI отдельная загрузка не нужна: он встроен в полный пакет с сервером `StarRailAssistant_vX.X.X.zip` (либо установите `ServerDLC`). После распаковки WebUI обслуживается самим сервером — запустите сервер и откройте интерфейс в браузере.
* Для запуска SRA из исходников прочитайте [руководство для участников](CONTRIBUTING.md).
