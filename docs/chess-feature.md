# 中国象棋功能

## 功能说明

本功能为SRA添加了一个简单的中国象棋游戏，支持双人对战模式。

## 使用方法

### 运行游戏

```bash
cd StarRailAssistant
python tasks/ChessTask.py
```

### 游戏规则

1. **棋盘坐标**：
   - 行号：0-9（从上到下）
   - 列号：0-8（从左到右）

2. **输入格式**：
   ```
   起始位置 目标位置
   ```
   例如：`9,4 9,3` 表示将红方帅从(9,4)移动到(9,3)

3. **棋子走法**：
   - **车(車)**：只能走直线（横或竖）
   - **马(馬)**：走"日"字
   - **象(象/相)**：走"田"字，不能过河
   - **士(士/仕)**：走斜线一格，在九宫格内
   - **将/帅(将/帅)**：走直线一格，在九宫格内
   - **炮(炮)**：走直线，吃子需要隔一个棋子
   - **兵/卒(卒/兵)**：向前走一格，过河后可以左右走

4. **游戏结束**：
   - 当一方吃掉对方的将/帅时，游戏结束
   - 吃掉将/帅的一方获胜

## 功能特点

1. **完整的棋盘显示**：清晰显示所有棋子位置
2. **合法走法验证**：基本的走法规则验证
3. **中文界面**：使用中文显示棋子和提示信息
4. **简单易用**：命令行交互，输入简单
